## 国外便宜VPS的三种“便宜”口径，你买的是哪一种

VPS的便宜分三种，买之前要看清自己买的是端口、流量还是配置，不然很容易买错。

**限端口带宽**：给一个固定的上下行端口，流量不限。雨云洛杉矶一区入门是10M上/15M下，不限流量，¥20/月；二区是10M上/20M下，¥18/月。这类机器适合流量持续但峰值不高的站，比如个人博客、小型API、监控面板。

**限月流量**：给一个大端口，但每月流量有上限。野草云美国AMD 1C1G是500Mbps端口加1TB月流量，¥19/月，流量双向统计，用完限速1Mbps。这类机器适合短时高带宽、月流量能预估的场景，比如传文件、做备份、跑阶段性任务。

**小带宽不限流量**：端口很小，但流量不限。野草云NVMe 1C1G给5Mbps不限流量，¥19/月；LightLayer台湾年付入门款公开带宽是5Mbps，也属于这一类。适合爬虫、Bot、挂机监控这类一直有流量但不需要快的任务。

LightLayer的$4款给的是100Mbps不限流量，在低价档里算宽松。不限流量通常还有公平使用条款，下单前翻一下服务条款，别拿它跑持续大流量。
